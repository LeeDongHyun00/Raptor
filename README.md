# 트라이혼 (Trihorn) — 격주 콘텐츠 오토파일럿

> A-06 트리케라톱스(4) 프로젝트

제품 자료와 실제 사용 화면 캡처만 넣어 두면, AI가 기술적 차별점을 분석하고 그때그때의 트렌드를 엮어
**네이버 블로그 글**과 **인스타그램 카드뉴스**를 격주로 자동 제작해 주는 마케팅 자동화 웹 서비스입니다.
MVP 대상은 티링크 비즈레코딩(통화녹음·CRM·AI 리포트) 1개사입니다.

이름은 세 개의 뿔(차별점 분석 · 트렌드 연결 · 멀티채널 생성)에서 따왔습니다.

## 화면 구성

| 경로 | 내용 |
|---|---|
| `/` | 대시보드 — 다음 자동 실행일, **지금 실행** 버튼, 승인 대기열, 생성 이력(다룬 주제) |
| `/materials` | 제안서·매뉴얼(PDF, PPTX), 화면 캡처, 가이드라인(엑셀 불러오기·직접 수정) |
| `/insights` | 차별점 분석 카드 — 일반 방식과의 비교, 근거 문서·페이지 |
| `/run?id=…` | 회차 결과 검토 — 블로그 글, 카드뉴스, 기획 근거, 가이드라인 충족도, 승인·반려 |

## 파이프라인

1. **트렌드 수집** — 네이버 데이터랩 검색어 트렌드(최근 2주 vs 직전 2주)와 뉴스 검색
2. **주제 선정** — 차별점과 맞는 트렌드를 고르고, 이전에 다룬 주제는 제외
3. **동시 생성** — 하나의 기획으로 블로그 글(캡처 배치·캡션)과 카드뉴스(6~8장, 본문, 해시태그)
4. **자동 검수** — 필수 키워드·분량은 코드로, 미션은 AI로 검사
5. **보완** — 지키지 못한 섹션만 다시 작성(최대 2회)
6. **담당자 승인** — 승인 대기열에 올리고, 승인 후 복사·HTML 내보내기·PNG 다운로드로 직접 업로드

‘광고’ 표기는 모델에 맡기지 않고 코드가 항상 넣습니다(블로그 본문 맨 위, 카드 첫 장, 인스타그램 본문 첫 줄과 해시태그).

## 기술 스택

- Next.js 16 (App Router, TypeScript), Tailwind CSS 4, Vercel 배포
- Anthropic Claude API — `claude-sonnet-5-5`(문서 분석·이미지 인식·기획·작성), `claude-haiku-5-5`(미션 검수)
- 네이버 데이터랩 검색어 트렌드 API, 네이버 검색 API(뉴스)
- 카드뉴스: `next/og`(Satori)로 1080×1350 PNG 렌더링, Pretendard 폰트 내장
- 문서 처리: PDF는 Claude에 직접 입력, 엑셀 가이드라인은 SheetJS, PPTX는 슬라이드 텍스트 추출
- 저장: Supabase(`trihorn_kv` 테이블) 또는 로컬 JSON 파일
- 자동화: Vercel Cron

## 실행

```bash
npm install
npm run dev
```

환경 변수 없이도 **데모 모드**로 전체 흐름이 동작합니다(샘플 자료·샘플 트렌드·샘플 응답).
실제 생성으로 바꾸려면 `.env.example`을 `.env.local`로 복사해 값을 채웁니다.

| 변수 | 없을 때 동작 |
|---|---|
| `ANTHROPIC_API_KEY` | 데모 모드: 미리 준비한 샘플 주제 3개로 생성·검수·보완을 재현 |
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | 샘플 트렌드 데이터 사용 |
| `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` | `.data/` 로컬 파일에 저장 (Vercel에서는 `/tmp`라 재시작 시 초기화) |
| `CRON_SECRET` | Vercel에서 `/api/cron` 호출 거부(503) |

Supabase를 쓰려면 SQL 편집기에서 `supabase/schema.sql`을 한 번 실행합니다.

## GitHub Pages 데모

서버 없이 흐름을 확인할 수 있는 정적 데모를 GitHub Pages에 배포합니다(`.github/workflows/pages.yml`).

- 주소: `https://<계정>.github.io/Raptor/`
- 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정해야 합니다.
- 데모 모드 전용입니다. 샘플 파이프라인이 브라우저에서 실행되고 상태는 그 브라우저의 localStorage에 저장됩니다.
- 파일 업로드, 실제 문서 분석, Claude·네이버 연동, 격주 Cron은 서버 배포(Vercel)에서만 동작합니다.
- 카드뉴스 PNG는 샘플 주제용으로 미리 렌더링한 파일(`public/demo-cards/`)을 씁니다. 카드 디자인이나 샘플 문구를 바꾸면 데모 모드로 서버를 띄운 뒤 `npm run render:demo-cards`로 다시 만듭니다.

로컬에서 정적 빌드를 만들려면 `PAGES_BASE_PATH=/Raptor npm run build:pages`를 실행합니다(결과물은 `out/`).

## 격주 스케줄

Cron 문법으로는 "2주마다"를 표현할 수 없어서, `vercel.json`은 매주 월요일 09:00(KST)에 `/api/cron`을 호출하고
핸들러가 마지막 실행일로부터 13일 이상 지났을 때만 실제로 실행합니다. 시연용 **지금 실행** 버튼은 주기와 무관하게 바로 실행합니다.

## 가이드라인 엑셀 형식

첫 열에 구분, 둘째 열에 내용을 적습니다. 키워드 행은 셋째 열에 최소 횟수를 적을 수 있습니다.

| 구분 | 내용 | 횟수 |
|---|---|---|
| 키워드 | 비즈레코딩 | 3 |
| 키워드 | 통화녹음 | 2 |
| 미션 | 마지막 문단에 도입 문의로 이어지는 문구를 넣는다 | |
| 구성 | 문제 제기 → 해결 방법 → 문의 안내 | |
| 글자수 | 1,000자 이상 | |

## MVP에서 제외한 것

블로그·인스타그램 자동 게시, AI 이미지 생성, 성과 분석과 자동 개선, 로그인·다중 사용자 관리.
로그인이 없으므로 배포 URL을 아는 사람은 누구나 자료를 올리고 실행할 수 있습니다. 공개 배포 시에는 Vercel 배포 보호 등으로 접근을 제한하세요.
